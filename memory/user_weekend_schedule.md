Saturday is a rest and leisure day (chill-day). The user does not want household chores, admin tasks, repairs, cleaning, or errands on Saturday.

Sunday is for household and admin: cleaning, repairs, configuration tasks, buying supplies, running errands.

**How to apply in morning ritual:**
- Saturday plan → propose only leisure/hobby items from Someday/Maybe. Never suggest household or admin tasks.
- Sunday plan → propose household and admin tasks. Leisure/hobby items are deprioritized.
