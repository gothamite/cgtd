name: Check before asking
description: Always look up Notion/Gmail/Calendar yourself before asking the user a question
type: feedback
---

Before asking the user any question — check Notion, Gmail, or Calendar yourself first.

Only ask the user if the data is genuinely unavailable in all accessible sources (Notion search returns nothing, Gmail search returns nothing, Calendar has no relevant events).

**Why:** The user expects the assistant to be proactive and use available tools. Asking questions that could be answered by a quick lookup wastes the user's time and breaks the flow.

**How to apply:** When about to type a clarifying question, first run the relevant lookup. Ask only if the lookup fails.
