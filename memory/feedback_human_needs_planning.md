Never build a wall-to-wall task schedule without breaks. Users need food and rest.

**Why:** A day packed back-to-back with tasks and zero breaks is not a valid plan — it's a recipe for burnout and missed meals.

**How to apply in morning-ritual:**
1. Always reserve a lunch block — use `config.user.lunch_home` / `config.user.lunch_work` if set. If not set, leave a 30–45 min gap at a reasonable midday time (typical: 12:00–14:30 range depending on day type). Also reserve at least one 15–20 min rest break in the afternoon.
2. On weekends especially: be conservative — don't fill every free slot. Leave breathing room.
3. If existing anchors already leave no room for breaks, flag this explicitly rather than silently accepting the overloaded schedule.
4. Never slot additional NAs into a day that's already missing meal/rest time without first flagging the overload.
