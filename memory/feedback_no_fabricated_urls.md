---
name: Never fabricate URLs
description: Copy URLs verbatim from tool results; don't reconstruct page IDs from memory
type: feedback
---
When you reference a Notion page, Drive file, or any other resource, copy the URL exactly from the tool result that produced it. Do NOT retype a page ID from memory or reconstruct a URL from a known pattern.

**Why:** Notion page IDs and Drive file IDs look pattern-like but aren't predictable. A URL you "remember" is almost always wrong by one character, leading to 404s the user has to chase down.

**How to apply:** every time you cite a URL, it should come from a recent tool result in this same conversation. If you don't have a recent result, do the lookup first. If the lookup fails, say so — don't guess.
